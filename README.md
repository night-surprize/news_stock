# Реакция российских акций на новости

Проект оценивает краткосрочную реакцию акций Московской биржи на новостные заголовки. Для каждого события рассчитывается доходность акции относительно IMOEX через 1, 3 и 5 торговых дней. Затем на этих наблюдениях обучаются отдельные модели для величины и направления реакции.

Это исследовательский проект, а не торговая стратегия. На текущей выборке регрессия не превосходит нулевой прогноз по MAE, поэтому результат следует читать как демонстрацию пайплайна и сценарную оценку, а не как инвестиционную рекомендацию.

## Что входит в проект

- сбор заголовков через Google News RSS по 16 российским эмитентам;
- загрузка дневных свечей из MOEX ISS;
- привязка публикаций к торговым сессиям;
- расчёт аномальной доходности относительно IMOEX;
- хронологическое разделение данных без перемешивания;
- Ridge для величины реакции и Logistic Regression для её направления;
- CLI для прогноза по новому заголовку;
- готовые данные, модель и результаты для запуска без сети.

В репозитории находятся 867 пар "новость - акция" за период с 01.01.2021 по 31.10.2026. После привязки к котировкам и фильтрации осталось 684 наблюдения.

## Установка

Требуется Python 3.11 или новее. Команды выполняются из корня проекта.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

macOS и Linux:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Версии зависимостей зафиксированы, потому что совместимость моделей `joblib` между разными версиями scikit-learn не гарантируется. Загружайте `model_bundle.joblib` только из доверенного репозитория.

## Быстрая проверка

```bash
python -m unittest discover -s tests
```

Тесты не обращаются к сети. Они проверяют правила обработки заголовков, выбор компаний, целостность подготовленных данных и прогноз с сохранённой моделью.

## Прогноз по новой новости

```bash
python -m src.predict_news \
  --text "Сбербанк сообщил о росте чистой прибыли и рекомендовал дивиденды" \
  --source "РИА Новости" \
  --published-at "2026-11-05T12:30:00+03:00"
```

Если компания прямо не названа, тикеры можно передать вручную:

```bash
python -m src.predict_news \
  --text "Изменена экспортная пошлина на минеральные удобрения" \
  --tickers PHOR,AKRN
```

Подробный результат сохраняется в `results/latest_prediction.csv` и `results/latest_prediction.json`. Поле `forecast_3d_pct`, например, содержит прогноз аномальной доходности через три торговых дня в процентах. Это изменение относительно движения IMOEX, а не прогноз абсолютной цены акции.

## Повторное обучение

Подготовленные `news_raw.csv` и `moex_prices_daily.csv` уже включены, поэтому датасет и модель можно пересобрать без сети:

```bash
python -m src.build_dataset
python -m src.train_model
```

Полная загрузка исходных данных и обучение:

```bash
python run_pipeline.py
```

Отдельные этапы сбора:

```bash
python -m src.collect_news --per-query 2 --workers 20
python -m src.collect_prices --workers 12
```

Для них нужен доступ к Google News RSS и MOEX ISS. RSS используется как поисковый индекс: проект сохраняет заголовок, время из ленты, название СМИ и ссылку Google News, но не копирует полный текст статьи.

## Расчёт целевой переменной

1. Время публикации переводится в московское.
2. Новость до 18:45 в торговый день относится к этой сессии. Более поздняя публикация относится к следующей сессии.
3. Базой служит закрытие предыдущего торгового дня.
4. Для акции и IMOEX считается доходность до закрытия 1-й, 3-й и 5-й сессии.
5. Доходность IMOEX вычитается из доходности акции.
6. Заголовки, уже сообщающие о движении акции, исключаются как возможная утечка цели.
7. Наблюдения с экстремальными изменениями цены удаляются по фиксированному порогу.

Текст представлен TF-IDF по словам и биграммам. Дополнительно используются тикер, сектор, СМИ, тип события, правиловая тональность и календарные признаки. Гиперпараметры выбираются на внутреннем временном отрезке обучающей выборки. Внешняя проверка также хронологическая.

## Ограничения

- модель видит заголовки, а не полные тексты;
- время в RSS может отличаться от времени на странице СМИ;
- Google News не даёт полной выборки публикаций;
- несколько заголовков могут относиться к одному инфоповоду;
- вычитание IMOEX не заменяет полноценную факторную модель;
- дневные данные плохо отражают события внутри торговой сессии;
- один хронологический тест не подтверждает стабильность результата.

Главное направление дальнейшей работы - улучшение данных: дедупликация инфоповодов, точное время первичной публикации, корпоративные раскрытия и более частые котировки.
